A controller-friendly game launcher for macOS, styled after the Aurora 360 dashboard. Point it at your game folders and emulators, and it gives you a cover-art carousel you can browse with a gamepad, keyboard or mouse.


Tonedash is a launcher only. It doesn't include any emulators, games or ROMs. You MUST supply your own legally owned roms!

Features

Cover-art carousel with a glowing selected tile, reflections and smooth animation

Full gamepad support through Apple's GameController framework (Xbox, PlayStation, and other supported controllers)

Multiple libraries, each with its own games folder, emulator and launch arguments, plus a combined "All Games" view

Automatic game identification: reads each game's ID straight from the file, looks up its official name, and downloads cover art

Custom covers: pick a PNG or JPG from Finder for any game, from the controller or the mouse

Custom dashboard background: use any image you like, or return to the default gradient

Fullscreen handoff: Tonedash leaves fullscreen when a game starts so emulators can go fullscreen properly, then returns to fullscreen when the emulator quits

Wide format support: discs and cartridge ROMs from NES through Switch (see Supported file types)
